El proyecto

Me he lanzado a la IA local: ComfyUI para los grafos de generación de imágenes, WorkflowUI para publicar esos grafos como aplicaciones sencillas y un LLM local para el texto. Para usarlos a diario, diseñé mi propia interfaz, una conversación en la que cada mensaje se convierte en una imagen.

Es un pequeño servicio FastAPI con una página Alpine.js. El navegador solo habla con el servicio. El servicio llama a una lista fija de rutas de WorkflowUI y lee ComfyUI sin escribir nunca en él.

Las capturas proceden de una copia con conversaciones de demostración. Los prompts reescritos que muestran son ilustrativos: esa visualización está construida y probada, y se activará con la próxima versión del flujo.

Lo que hice con IA

  • Grabar el servidor real antes de programar

    Claude exploró primero WorkflowUI en modo de solo lectura, su descripción de API y su código de front-end, para encontrar el formato exacto de las peticiones. Después grabó una generación real completa, más los casos de cancelación, error y generación desconocida. Solo entonces escribió código.

  • Comportamientos ocultos, medidos

    Sin sus vínculos de campos, WorkflowUI responde 200 pero ejecuta los valores por defecto. Un grafo puede anunciar un éxito sin imagen. Una reescritura fallida devuelve en silencio el prompt escrito. Cada trampa se midió, se documentó y se convirtió en una regla.

  • Un LLM local en la cadena

    Cada idea la reescribe un LLM local antes de la difusión. Una copia del flujo expone el texto reescrito, y un parche de 4 líneas en el nodo de reescritura hace que Reintentar vuelva a ejecutar de verdad la reescritura.

  • Una lista blanca, no un proxy

    Las rutas de administración de WorkflowUI están abiertas en la red local, así que el servicio nunca debe reenviar llamadas arbitrarias. Conoce 12 llamadas de WorkflowUI y 2 de ComfyUI de solo lectura, y limita cada valor: una imagen por generación, tamaños de hasta 2048 píxeles.

  • Tests sin GPU

    58 tests se ejecutan en menos de un segundo. Reproducen 24 respuestas grabadas en el servidor real, errores incluidos, sin ningún servidor falso escrito a mano.

  • Un progreso honesto, sin mensajes fantasma

    El progreso se envía en directo y se estima a partir de las 100 últimas generaciones; se detiene en el 95 % hasta el final real. Cada mensaje se guarda antes de lanzar la generación y se elimina si el servidor la rechaza.

Lo que fue difícil

Un 200 que ejecutaba otra cosa

El problema
En la primera prueba, WorkflowUI respondió 200 pero generó sus valores por defecto: a la petición le faltaban los vínculos de campos y nada lo indicaba.
Lo que hice
Claude leyó el código de front-end para encontrar el cuerpo exacto y luego cada llamada se grabó en el servidor real y se reprodujo en los tests.
El resultado
El servicio envía siempre los vínculos, y un test falla si desaparecen.

Un éxito sin imagen

El problema
ComfyUI puede dar por buena una generación aunque la rama de imagen se haya rechazado: le basta con un nodo de salida válido.
Lo que hice
Una regla en el servicio: una generación terminada sin imagen es un error, que se muestra en la conversación.
El resultado
Un ajuste no válido aparece ahora como un error claro en 1,5 segundos, en lugar de un éxito vacío.
