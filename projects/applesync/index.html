AppleSync

A verifiable backup of iPhone photos to Windows, over Apple's protocol, with a device simulator that injects failures.

TechnologiesPython, PySide6, pymobiledevice3, SQLite, pytest, GitHub Actions

The project

The tool copies an iPhone's whole photo library to a PC, bypassing Windows Explorer, which silently loses files. It inventories twice, resumes a copy to the byte and rereads every file to prove the backup is complete.

What I did with AI

  • Reasoned decisions

    16 decisions in a "chosen, alternatives rejected, why" format, and a "decisions I am least sure about" section with six hypotheses to confirm on the real device.

  • A simulator with fault injection

    Silent truncation, disconnection, a read failing at byte N, a locked device: 40,000 files and 109 GB simulated without storing anything. Tests run without an iPhone.

  • Protocol-level work

    Seeking within a file is rebuilt by hand from the reference library, and verified by reading the position back.
