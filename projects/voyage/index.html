Voyage

A trip planner where every place the LLM proposes exists, is well rated and sits in the right spot on the map.

Category
Apps

Status
Working, tested on a real 10-day trip

The project

You enter a destination, dates and preferences, such as meal times. The AI proposes a day-by-day plan, with photos, ratings, weather, a map and real travel times.

The principle learned while building it: a prompt guarantees nothing. Every important rule was moved into code.

What I did with AI

  • An LLM grounded in verified places

    Google Places supplies candidates rated 4.0 and up, grouped into 3 km zones. The LLM only returns a short code per place. Code binds the real name, coordinates, rating and photos.

  • Three providers with fallback

    Gemini, Groq and MiniMax, called without SDKs, with automatic fallback, three retries, enforced JSON output and a keyless demo mode.

  • 8 corrections after the LLM

    Duplicates, day structure, robust geocoding, meal times, invented claims removed, ordering by proximity, then real travel times.

  • Edit without starting over

    One day can be regenerated from a free-text instruction, and one place replaced with a reason. The rest of the trip stays untouched, and each trip is a single JSON file written atomically.
