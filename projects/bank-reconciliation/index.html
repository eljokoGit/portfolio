LLM-assisted bank reconciliation

An app that fetches bank transactions over PSD2, classifies them in layers, and only lets the LLM suggest.

The project

The app connects to banks through the European PSD2 API and fetches new transactions every day. It classifies them with safe rules, then by comparing them to years of hand-kept spreadsheets.

An AI model only suggests a category for the rest, backed by web search. A human approves each suggestion in one click.

What I did with AI

  • An LLM queue without an API key

    The server writes batches as files, synced by Syncthing. A Cowork task running Haiku runs a check script and only wakes an Opus sub-agent when batches are waiting.

  • Suggestions only

    A documented U-turn after too many errors, even with web search: the LLM no longer classifies anything on its own. The "misc" category is banned, some categories are human-only, one pass per transaction.

  • Two-layer memory

    An as-built spec updated with every change, a short memory pruned continuously, and a hook that forces a reread after every context compaction.

  • Guardrails for destructive operations

    Mandatory backup before any operation over 100 rows, append-only log before and after each query, no change without explicit confirmation.

What was hard

One click, 54 wrong transactions

The problem
Propagating a classification to similar transactions looked like a time saver. On a generic bank label, it tagged 54 unrelated transactions at once.
What I did
Propagation became opt-in, off by default, and the reason is written next to the code.
The result
A classification only ever touches the transaction the human confirmed.

The twin purchases

The problem
Two identical purchases on the same day merged into one: deduplication ignored the bank identifier.
What I did
Fix, then an audit against statements. Automatic back-filling was refused because the script produced 4% false positives.
The result
53 missing transactions found over 9 months, and a monthly totals check instead.

The silently dead session

The problem
The PSD2 consent was still valid, but the bank session had expired: 6 weeks not synced.
What I did
Account matching by IBAN hash, a reconnect status and a one-click button.
The result
The failure now shows the same day, instead of six weeks later.
