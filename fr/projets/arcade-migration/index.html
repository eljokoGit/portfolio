Migration de borne pilotée par un agent

La migration d'une borne d'arcade vers une distribution Linux dédiée, menée par Claude Code en SSH, sans jamais rien supprimer.

Catégorie
Données
Période
Août et septembre 2026

TechnologiesLinux, SSH, Python, PowerShell, Claude Code

Le projet

Inventaire d'un disque de plus de 1 To, plan de migration, mise en ordre d'un catalogue de plus de 100 000 fichiers par scripts, réglages du système et restauration sur une nouvelle machine.

Ce que j'ai fait avec l'IA

  • Un agent qui agit, sous règles

    Claude Code exécute lui-même en SSH. Rien n'est supprimé, tout est déplacé, et chaque script tourne en simulation tant qu'on ne lui passe pas `--go`.

  • Un protocole de fichiers numérotés

    Les consignes et les rapports s'échangent en fichiers numérotés, de 001 à 066. Le journal sert de source de vérité après chaque compactage.

Ce qui a été difficile

Deux hypothèses fausses

Le problème
Des entrées affichaient la fiche d'un voisin. J'accusais la base de données, l'agent accusait des requêtes parallèles.
Ce que j'ai fait
Nouvelle interrogation par empreinte, puis lecture du titre inscrit dans les fichiers eux-mêmes.
Le résultat
La vraie cause : des fichiers mal nommés à la source. 24 paires corrigées.
