Handled by AIDeterministic codeHuman decision

  • The spec before the code

    Every project starts with a written spec and a decision log. The agent codes against a document, not a vibe.

    215 citations of the official standard before the first line of VERI*FACTU code. VERI*FACTU invoicing

  • The LLM suggests, code decides

    Important rules live in deterministic code. The model picks or drafts, a mechanical check accepts or rejects.

    16 rules enforced by the park copilot's server, which rejects any plan that breaks one. Theme park day copilot

  • Don't trust, verify

    Hooks block any red push, a changed test is replayed on the old code, sceptic agents try to refute. A reported success is not proof.

    279 of Étoilia's 292 commits co-written with Claude, all under that guardrail. Étoilia

  • A human stays in charge

    Agents ask instead of inventing. Their doubts reach me in a queue, and an explicit answer always beats an inference.

    The PMO cockpit never writes to the knowledge base: each of my answers becomes a file that an agent applies. Multi-agent PMO copilot

  • Agents that run alone, and repair

    Scheduled tasks, a light model that checks before waking a heavy one, nightly repair limited to a written runbook.

    On my agent platform, an email only arrives for what automatic repair could not fix. 24/7 agent platform

  • Memory that outlives sessions

    CLAUDE.md, memory files and logs reread after each compaction: the agent resumes where it stopped, with the lessons learned.

    53 Claude Code memory files, and a 4,921-line log on a single project. Étoilia
